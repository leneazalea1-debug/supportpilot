SupportPilot AI — PWA V3

No Node.js is required.

Preview:
Open index.html to preview the interface.

Install as an app:
1. Upload all files/folders from this ZIP to a static web host that provides HTTPS.
2. Open the hosted HTTPS address in Chrome or Microsoft Edge.
3. Choose Install SupportPilot / Install app.
4. It will then launch in its own standalone app window.

The service worker provides the offline app shell after the first successful hosted visit.

V3 remains a local rule-based agent-assist prototype and is NOT connected to a live AI model. Never place a private AI API key directly in app.js. A later version should use a secure hosted backend/serverless function.

Privacy: Do not enter real customer IDs, bank details, or other personal information unless your organisation has approved the system and its data handling.
